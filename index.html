About the Project

Intelligent Robotics for Modern Airports

This project, hosted at the Advanced Research and Innovation Center (ARIC) within Khalifa University, aims to fully automate common airport operations including luggage handling from check-in, conveyor belts, UMD processes, carts, and more.

At its core, a central Multimodal Large Language Model (MLLM) receives natural language task instructions from operators, processes contextual information about the robot's capabilities, sensor data, and environment state, then generates and executes high-level symbolic plans to accomplish complex airport tasks autonomously.

The robot platform is proudly developed and manufactured in the United Arab Emirates, reflecting the UAE's vision for local innovation and advanced technology development.

System Architecture

How It Works

  • 1
    User Prompt Operator issues a natural-language task (e.g., "Sort all luggage in Hall A").
  • 2
    MLLM Reasoning The MLLM processes robot metadata, sensory data (LiDAR, RGB-D, IMU), task parameters, and environment state.
  • 3
    Symbolic Plan Generation Generates a high-level plan decomposed into step-by-step sub-tasks and selects the appropriate tools.
  • 4
    Execution & Feedback The Execution Manager carries out actions, records robot states, and feeds results back into the loop.
  • 5
    States Memory Environment state is maintained as JSON/TF/XACRO, tracking all known objects and mission history.

Simulation Environment

Realistic Airport Scenario in NVIDIA Isaac Sim

To accelerate development and safely validate our framework before real-world deployment, we have constructed a high-fidelity airport scenario within NVIDIA Isaac Sim. The environment faithfully replicates key airport operational areas including baggage claim halls, check-in counters, conveyor belts, and UMD zones.

The simulation enables full end-to-end testing of the MLLM-driven pipeline — from natural language task input through symbolic plan generation to robot execution — under diverse conditions and edge cases that would be difficult or unsafe to test in a live airport environment.

Real-World Experiments

Hardware Demonstrations

Autonomous Navigation

The Picker 2.0 platform navigating autonomously through a structured environment. The robot builds and maintains an occupancy map in real time, plans collision-free paths, and localizes itself using onboard LiDAR and odometry — a prerequisite for any airport deployment scenario.

Grasping Experiment — Pick & Place

Demonstration of the robot's ability to detect, localize, and grasp target objects using 6-DoF pose estimation. The manipulation pipeline integrates visual perception with optimal grasp planning to reliably pick luggage-type objects from unstructured surfaces.

Grasping Experiment — Varied Objects

Testing grasp success across objects of varying size, shape, and weight. The system adapts grasp strategies using tactile slip estimation and control to ensure secure object handling throughout the manipulation sequence.

Grasping Experiment — Placement Precision

Evaluating precise placement of grasped objects into designated target locations (e.g., conveyor slots, carts). The robot uses visual confirmation and feedback from the Execution Manager to validate successful task completion and update the environment state.
